# SmartCounter

SmartCounter es una vertical contable sobre el core actual de SmartExcel/poc-agente-pyme.

## Para quien es

Esta vertical esta orientada a:
- estudios contables de Argentina
- contadores independientes de Argentina

## Problema que resuelve

SmartCounter apunta a convertir planillas contables caoticas en datos revisables:
- interpreta Excel desestructurado
- clasifica tipo de planilla
- mapea columnas a campos canonicos
- normaliza datos
- senala ambiguedades y riesgos
- prepara revision humana asistida
- conserva memoria operativa por cliente

## Relacion con el core actual

El core actual procesa Excel locales y genera hallazgos operativos. SmartCounter se define como una capa especializada encima de ese nucleo, sin reemplazarlo.

## Que NO es

- No es ERP.
- No es dashboard generalista.
- No es sistema contable completo.

## Estado actual

Vertical abierta documentalmente. No implementada todavia como modulo funcional separado.
